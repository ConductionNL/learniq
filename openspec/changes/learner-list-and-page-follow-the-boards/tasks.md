Saved views (decision): the four views stay the page's quick filters with counts, which is what each school kind's board draws; storing them per example set adds nothing a teacher sees. Present this year built 24 Nov: the summary counts absent days only (present marks are not read), so `presentPercent` is the school days held so far (`SchoolYearSoFar`: `LeaveCalendar::schoolDays()` from the school year's first day up to today, weekdays outside the school's holidays) less the days absent, of the days held, in whole percent (null before the first school day); the list shows it as "Present this year" / "Aanwezig dit jaar". Tests: `PupilListTest::testPresentThisYearIsAShareOfTheSchoolDaysHeld`, `PupilListServiceTest`, `SchoolYearSoFarTest`.
