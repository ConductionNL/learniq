# Turn your Word and PowerPoint files into lessons

You already have lessons in Word and PowerPoint. Learniq turns each file into a lesson draft, so you do not retype them. You pick the files: learniq reads nothing until you confirm a file.

## Goal

By the end you have chosen an onboarding folder, dropped a file in it, and imported that file as a draft lesson in one of your courses.

## Prerequisites

- You can create lessons in learniq (teachers, coordinators and administrators can).
- The course you want the lesson in exists.
- For PowerPoint: your school runs an OpenRegister version with the presentation reader. Without it, Word files work and PowerPoint files wait in your list.

## Steps

1. Open **Learning** and choose **Lessons from Word and PowerPoint**.
2. Choose **Choose folder** and pick one folder in your own files, for example `Lessen inbox`. Learniq watches only that folder, and only files you put directly in it.
3. Drop a `.docx` or `.pptx` file in the folder, from your computer, the desktop client or the Files app.
4. You get a notification: "New file in your lesson folder". Choose **Review**. The file is now in the list under **Files waiting for you**.
5. Check the file. A lesson is visible to everyone in the school, so a file with pupil names, marks or notes about a pupil does not belong in a lesson. If it does not fit, choose **Dismiss**.
6. Pick the course and choose **Import as lesson draft**.
7. Choose **Open in the lesson composer**, check the blocks, and keep editing. The lesson stays a draft until you publish it from the course builder.

## What you get

- **Word**: every heading starts a new text block with that heading on top. Lists and tables come along. Each picture becomes a material in the lesson and a media block under its section. The title of the document names the lesson.
- **PowerPoint**: every visible slide becomes a text block with the slide title on top. Speaker notes become a teacher note right below it. Hidden slides are left out, and the import tells you how many.
- The original file stays linked to the lesson as a material, so you can always open it.

## Good to know

- A teacher note is not shown in the lesson player. It is still part of the lesson object, so keep answers to tests out of it.
- Pictures go to `Scholiq/<school>/course-imports/` in your files.
- **Stop watching** clears the folder. Files already in your list stay there.
- Old formats (`.doc`, `.ppt`) and PDF are not read. Save them as `.docx` or `.pptx` first.
